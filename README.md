# No Man’s Sky: атлас выживания

[Открыть публичный атлас](https://mo7268523-ctrl.github.io/nms-atlas-survival/)

Русский интерактивный каталог с поиском предметов, обратным поиском по ингредиентам, альтернативами рецептов, деревом производства и расчётом ресурсов.

## Проверка данных

- Снимок игрового экстракта [NMSE](https://github.com/vectorcmdr/NMSE/tree/078cb7c99f47f9d799da8f82c70a3c6af5b13a40/Resources/json) от 19 ноября 2026. Состав и выход операций берутся из `Recipes.json`; материалы крафта, строительства, установки и ремонта — из `RequiredItems` по игровому ID.
- [Сводка проверки](audit.json) содержит число записей и операций, проверку связей и привязку иконок. Наличие ID в выгрузке не гарантирует, что элемент доступен в обычном сохранении.
- Пресет «Выживание»: стандартные затраты на изготовление, 500 единиц обычного сырья в ячейке экзокостюма, до 250 на входной слот очистителя. [Настройки сложности](https://www.nomanssky.com/waypoint-update/) могут переопределить лимиты. Расход топлива и экран ремонта считаются отдельно.
- Названия и игровые ID помогают найти точное описание в игре. Этот каталог содержит самостоятельные справки о назначении по структуре данных и ссылки на источники. Иконки показываются по публичным ссылкам экстракта NMSE, права на игру и её графику принадлежат Hello Games.

## Запуск и сборка

Откройте `index.html` или разместите корень репозитория на статическом HTTPS-хостинге. Сервер приложений не нужен. Внешнее соединение нужно для оригинальных иконок и переходов к источникам.

Скрипт `build_data.py` принимает путь к `Resources/json` в зафиксированном снимке NMSE, список путей `git ls-tree -r --name-only HEAD Resources/images`, JSON прежнего атласа, таблицу его локализации и SHA NMSE. Он формирует `data.js` и `audit.json`.
